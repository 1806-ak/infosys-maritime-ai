# Infosys Springboard Internship 7.0 — Milestone 1

## Project: Authentication System

This project implements a Streamlit-based authentication system with login, signup, JWT authentication, email OTP verification, and password reset functionality.

### Features
- User login and signup
- Email and password validation
- JWT-based authentication
- Gmail OTP verification for password reset
- Role-based Admin and User dashboards
- SQLite database for user records

### Technologies Used
- Python
- Streamlit
- SQLite
- JWT
- bcrypt
- Gmail SMTP
- Google Colab
- ngrok

### Setup
1. Install the required Python packages.
2. Configure the required credentials using environment variables or Google Colab Secrets.
3. Run the Streamlit application.
4. Use ngrok to expose the application for testing.

### Security
Do not commit passwords, Gmail app passwords, JWT secrets, or ngrok authentication tokens to GitHub.
